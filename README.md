# ToolPool – Online Tool Rental Platform

## 📌 Project Overview

ToolPool is an online tool rental platform designed to make it easier for users to browse, explore, and rent tools for various personal and professional requirements.

The platform provides an organized interface where users can explore different tools, view their details, and access rental-related functionalities.

## ✨ Features

- **Home Page:** Provides an introduction to the platform.
- **Browse Tools:** Explore available tools through a dedicated browsing page.
- **Tool Details:** Individual detail pages for different tools.
- **User Authentication:** Login and signup pages.
- **Add Tools:** Interface for adding tools to the platform.
- **Payment Page:** Dedicated payment interface.
- **Guidelines:** Provides information about tool usage and rental guidelines.
- **Responsive Interface:** Organized web pages for convenient navigation.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/gauridyappa/ToolPool.git
```

### 2. Navigate to the Project Directory

```bash
cd ToolPool
```

### 3. Run the Project

Open `home.html` in your preferred web browser.

No additional server setup is required for basic static-page viewing.
